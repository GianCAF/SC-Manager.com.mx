# SC-Manager.com.mx

Reconstrucción de SocioManager como SPA con React, Vite, TypeScript y Tailwind CSS.

## Primera entrega

Esta versión contiene exclusivamente la landing page y una ruta visual provisional para el acceso. No incluye Firebase, Supabase, autenticación, persistencia, almacenamiento ni lógica real para el formulario de contacto.

## Desarrollo

```bash
npm install
npm run dev
```

## Validación

```bash
npm run lint
npm run build
```
